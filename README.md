# 知星

> 把考试复习变成一张会长大的星图。

知星是一个**单机、离线优先、手机优先**的学习系统：知识点是星球，前置关系是航道，掌握度是星球的发展等级。它先解决「今天该学什么、错在哪、记住没有」，游戏层只读取这些数据，不反过来绑架学习。

当前版本 v0.7：纯净学习模式（题库 + 间隔重复 + 掌握度 + 错题本 + 统计 + 星图）已经可用，六科 335 个知识点全部配齐题库（1839 道自编题），语文补上 77 篇高考必背古诗文的完整栏目与 380 道抽句题；真题作答会回流到学习数据；游戏层有一个只读数据的战斗原型。

## 现在能做什么

- **六科知识体系**：数学、物理、化学、政治、英语、语文，335 个知识点、**1839 道题**（单选 734 / 填空 526 / 多选 271 / 判断 211 / 大题 97），知识点覆盖率 100%，支持单选、多选、判断、填空、大题。政治按「物化政」组合优先接入。
- **古诗文栏目**（语文）：77 篇高考必背古诗文（诗 23 / 词 15 / 曲 3 / 文 32 / 赋 2 / 辞 2），每篇有原文分段、逐条注释、逐段译文、赏析、名句高亮、易错字与高考提示；**背诵遮罩**可以逐行遮住原文自查背诵。配套 380 道抽句题（直接默写 / 情境默写 / 字词辨析 / 文化常识 / 赏析），校验器会逐字核对题目引文是否真在原文里。首页入口在「科目 → 古诗文栏目」或语文科目页顶部，`/texts` 里还有一个「默写专项」随机 20 道。每篇都可以在列表或详情里开关「启用」，停用的篇目仍能读原文、练本篇，只是不进默写专项的抽题库，方便把本轮不考的先放一边。
- **题库检索**：科目页题库支持按题干/来源/标签搜索、按题型筛选、分页加载。
- **今日学习**：自动混合「到期复习」和「新题」，按科目轮换，避免一晚上只刷一科。
- **间隔重复**：SM-2 变体。答错 10 分钟后重来；答对后 1 天 → 6 天 → 按难度系数增长；作答时长会影响评分。
- **即时反馈**：答错当场插入 3 题后重练；答对显示解析、正确答案、关联知识点；答错自动进错题本。
- **错题本**：连续答对 2 次自动移出；也可以手动移出或单题重做。
- **收藏与组卷**：题库里点星标收藏，在「我的 → 收藏练习」集中过一遍；「科目 → 综合测验」跨科组卷，交卷后逐题看答案与解析。
- **掌握度**：按题目所关联的知识点累计，21 天半衰期 + 贝叶斯平滑；薄弱知识点会优先出现在每日计划里。
- **知识星图**：一张覆盖六科 335 个知识点的总星图，可下钻到单科与板块；固定树状图与实时力导向原子图可切换，切到原子图时节点会从树杈原位流动展开。树状用曲线表达层级（进入树状会自动按板块展开），原子图用 Obsidian 式直线与持续微动的力模拟；右侧「力参数」可调向心力、斥力、连杆力与连杆距离（默认对齐 Obsidian），节点越大代表联系越多、考频/重难越高。支持缩放、拖拽、双指捏合、搜索、深链聚焦、节点详情与练 5 题。点击节点会聚焦镜头并把详情卡放到节点旁（可拖动），一级联系高亮、二级稍暗、其余淡出；点击空白取消选中，双击空白回到全局视角。节点使用电子云外观，背景有带随机连线的漂浮微粒；四个以上微粒抱团会形成带随机名字的「巨元素」，名字与出生/成长/吞噬/死亡播报词都可在力参数面板里增删，播报显示在左下角；游离微粒有较长的随机寿命，不再因为离开视野而立即消失。力参数面板里也能直接调游离元素数量、相互引力、短距斥力、向心引力、成键距离，以及用双滑块设置寿命随机范围。
- **真题卷**：已接入 2026 重庆化学整卷（18 题，图片题干版）。可看卷面、限时做 1–14 选择题（30 分钟 / 42 分，答题卡 + 断点续考 + 到点自动交卷），成绩页逐题对答案、看解析、报错；15–18 综合题在成绩页按整题自评打分。**交卷会写入学习系统**：每题进 SRS 复习队列、答错进错题本、按知识点累计掌握度，和普通题目共用一套排程。
- **真题知识点**：18 道题都用离线 OCR 识别题干后，人工对照 56 个化学知识点标注了 `kpIds` 与难度，因此真题成绩会直接反映到知识星图上。
- **录入真题**：科目页 → 录入真题，按向导填卷子信息、逐题加题与上传裁图，导出 `paper.json` / `qNN.json` 放进仓库即可（见 `docs/paper-import.md`）。
- **星域战斗（原型）**：科目页 → 星域战斗，回合制答题战斗，答对才命中，薄弱知识点出题更多。出题范围可多选到「科目 → 板块 → 知识点」三级，难度可自定限时与敌舰血量。只读题库，不写学习数据。设计草案见 `docs/battle-design.md`。
- **五种观察视角**：掌握度、优势、劣势、考频、重难；优势/劣势来自做题数据，考频/重难来自题库与知识元数据，颜色深浅按相对值。
- **统计**：累计答题、正确率、连续天数、14 天趋势、科目正确率、掌握度分布、最该补的洞。
- **数据自主**：全部进度存在本机 IndexedDB；支持导出/导入 JSON，换设备不丢档。
- **PWA**：可添加到手机主屏，断网也能打开已缓存的应用外壳。
- **操作方式**：Enter 提交答案；PC 鼠标侧键 / Alt+←→ 前进后退；手机在今日/科目/错题/统计/我的之间左右滑动切换；知识图内拖拽平移、滚轮/双指缩放，右侧滑块按钮调力参数。

## 快速开始

要求 Node.js 20+（开发时使用 Node 24）。

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # TypeScript 类型检查
npm run check:content  # 题库外键、环、题型校验
npm run build      # 产出 dist/
npm run preview    # 本地预览生产构建
```

手机访问：电脑和手机在同一局域网，`npm run dev -- --host` 后打开终端里显示的 `Network` 地址。

## 内容怎么更新

1. 在 `content/subjects.json` 加科目，在 `content/knowledge/<科目>.json` 加知识点与板块（先想清楚前置关系）。
2. 在 `content/questions/<科目>.json` 加题目，或新建一个 JSON 文件；`kpIds` 必须指向已存在的知识点。
3. 古诗文写进 `content/texts/<批次>.json`，抽句题写在 `content/questions/*.json` 里并带 `textId` / `quote` / `recite`。
4. `npm run dev` 或 `npm run build`。内容有错时浏览器控制台会打印 `[知星] 题库内容有问题：…`，非法题目会被丢弃，不会弄崩应用。
5. 也可以运行 `npm run check:content` 在命令行先做一遍外键、环、题型、古诗文引文与题库质量校验。
6. 详细字段、各题型示例和出题建议见 [题库格式](docs/content-format.md)。

内容规模自查：

```bash
npm run check:kp        # 每个知识点有几道题，列出 0 题/1~2 题的知识点
npm run check:quality   # 选项重复、答案不在选项、凑数选项、采分点对不上、题干重复
```

> 想用 AI 出题，直接用 [AI 出题提示词](docs/ai-question-prompt.md)。AI 生成的答案必须人工核对，尤其是大题评分细则。六科知识体系与 1839 道自编题都是 AI 按教材/课标结构生成的，正式备考前请逐科校对；标 `source` 为「自编练习」的题不是高考原题。

## 部署（PC 更新，手机游玩）

`npm run build` 后的 `dist/` 是纯静态文件，任意静态托管都可以。项目使用 **hash 路由 + 相对路径**，可以放在域名根目录，也可以放在子路径。

推荐顺序：

1. **Cloudflare Pages / Vercel / Netlify**：连 Git 仓库，构建命令 `npm run build`，产物目录 `dist`。国内访问不稳定时换国内对象存储。
2. **阿里云 OSS / 腾讯云 COS**：开静态网站托管，把 `dist/` 整个上传；绑定自定义域名并开 HTTPS。
3. 手机打开网址 → 浏览器菜单「添加到主屏幕」。PWA 与 Service Worker 需要 **HTTPS**（`localhost` 除外）。

更新内容的流程：电脑上改 `content/` → `npm run build` → 上传覆盖 `dist/` → 手机重新打开（导航请求是 network-first，会自动拿新版本；静态资源后台更新）。如果改了缓存策略，记得同步修改 `public/sw.js` 里的 `CACHE` 版本号。

## 学习机制（为什么这样设计）

- **先学习，后游戏**：即使游戏不好玩，题库、复习计划和错题本仍然有用。游戏层只消费学习数据。
- **做题即确认**：未来游戏里的关键操作会绑定一道题，答题质量决定操作成功率；现在先把「出题—作答—评分—记录」这条链路做扎实。
- **掌握度不是正确率**：它按知识点聚合、按时间衰减，并给少量样本做强平滑。刚做对一道题不会立刻「精通」。
- **错题不是收藏夹**：连续答对两次才移出，避免「看答案会了」的错觉。
- **每日计划有上限**：新题默认 10、复习默认 40，可在「我的」里调整。备考是长跑，宁可每天少一点，也不要三天打鱼。

## 游戏层接口

`src/engine/game.ts` 已经提供：

- `computeCivilization(data, questions, kpStats)`：文明快照（等级、经验、金币、点亮星球、舰队战力、科技层级）。
- `onGameEvent(name, handler)`：订阅 `answer`、`session:complete` 等事件。
- 设计约束：游戏层**只读**学习数据、只订阅事件；SRS、掌握度、错题本不依赖游戏代码。

接入方式与示例见 [游戏层接入](docs/game-integration.md)。

## 已知限制 / 下一步

- 内容目前靠改 JSON + 重新构建更新；录入向导能生成 JSON，但不能直接写仓库。
- 1839 道自编题与 335 个知识点都是模型按教材结构生成的，**没有逐题人工核对**；错的答案会进 SRS 复习队列，遇到可疑题目请以教材为准，并在真题成绩页用「报错」记录下来。
- 古诗文 77 篇中的长文有节选（已在 `excerpt` 与 `examNote` 注明）；异文写法放在可接受答案里，正文取通行版本。
- 真题库只有 2026 重庆化学一卷，其余科目待录。
- **真题卷不进仓库**：`content/papers/` 与 `public/papers/` 已被 `.gitignore` 排除（扫描图体积大、且有版权考虑）。克隆下来的仓库里没有真题数据，科目页的真题入口会是空的；要练真题，按 `docs/paper-import.md` 自行录卷或把卷子目录放到这两个位置，只有题目 JSON 会随仓库同步。
- 题库全量静态打包，首包 JS 约 1.6 MB（gzip 约 890 kB，katex/react/marked 已单独拆包）。局域网访问很快，公网首次加载偏慢，之后由 Service Worker 缓存；后续可按科目懒加载。
- 进度只在本机，没有云同步；换设备用导出/导入 JSON。
- 组卷考试按「全部题目 / 建议 30 分钟」固定，暂不能自选科目、题数或时长。
- 知识图已支持树/网切换、缩放拖拽、搜索与五种视角；跨科 `related` 关系还没有专门的跨星系视图。
- 星域战斗是原型：只吃文本题，非所选科目会跨科抽题；牌堆耗尽会循环；超时与失败路径还没细调。
- 真题图片题在学习流程里只能看图作答，不能框选或手写。
- 下一阶段优先级：六科真题库 → 战斗原型扩到图片题 → 更细的错题归因 → 手机端沉浸优化。
