# 星域战斗 · 设计草案

> 目标：让「做题」成为游戏里的**动作**，而不是游戏前的门槛。
> 三条方案都建立在同一套数据上：知识点 = 星球，掌握度 = 星球发展等级，题目 = 弹药。

## 共同前提

- 数据只读：战斗不写入 `attempts` / `cards` / `wrong`，不污染学习统计。想计入学习，用「练习 / 组卷 / 真题」。
- 题目来自现有题库，按知识点掌握度加权抽取：**薄弱知识点出题更多**。
- 手机竖屏可玩，一局 3~6 分钟。

---

## 方案 A：指令卡战斗（已实现原型，`/battle`）

**一句话**：每回合抽三张「指令卡」，每张卡绑一道题，答对才打得中。

- 玩家有结构值（hull）与护盾（shield），敌方舰队有 hp 与护盾。
- 每回合抽 3 张卡 → 选一张 → 作答 → 答对按 `1 + 0.25 × 连对` 倍率结算伤害；答错只造成 35% 伤害并被反击。
- 敌人每回合也会还手，护盾每回合恢复少量，逼玩家在「稳」和「快」之间取舍。
- 结算给评级（S/A/B/C）与最高连对。

**为什么适合备考**：单题节奏短、反馈强，答错立刻疼，符合「即时反馈 → 想再来一局」的循环。

**扩展方向**：卡牌带类型（火力 / 护盾 / 干扰），不同类型对应不同题型（选择=速攻，填空=精准打击，大题=轨道炮）。

---

## 方案 B：星球攻防（回合制轻 4X）

**一句话**：一回合 = 一次学习会话，星图就是战场。

- 星图上每个知识点是一颗星球，掌握度决定它的「防御力」和「产出」。
- 敌方文明按回合推进，攻击你最薄弱的知识点星球。
- 要守住，就得在那一回合练那个知识点：练完，星球防御上升，敌军被击退。
- 一局 = 一个「星区战役」，7 天为一轮，和复习周期对齐。

**为什么适合备考**：把「薄弱点」直接变成「被攻击的地方」，动机极强；和现有星图共用一套视觉，不用另做美术。

**成本**：需要一个回合推进器 + 敌军 AI + 星球状态，约 3~5 天工作量。

---

## 方案 C：远征 Roguelike（答题驱动的路线选择）

**一句话**：每次跳跃到一个星区，选一条路线，路线上每个节点是一道题。

- 三条路线：安全（简单题，收益低）、危险（难题，收益高）、未知（随机）。
- 答对推进，答错掉血；连对攒「跃迁能量」，可以跳过低价值节点。
- 每次远征 10~15 个节点，死亡即结束，但保留「星图碎片」用于永久解锁。

**为什么适合备考**：Roguelike 的重开成本低，适合碎片时间；难度曲线天然匹配「从易到难」。

**成本**：最高，需要地图生成、事件系统、永久进度。

---

## 选择建议

先做 A，因为它最省工且立刻可玩；等真题库和掌握度数据稳定后，再把 A 的「指令卡」接到 B 的星球战场上——那时你已经有了真实的薄弱点分布，B 的敌军 AI 才有意义。

C 建议放到最后，它依赖足够大的题库（>200 题）才有变化感。

## 已实现部分的边界

- 只抽文本题，跳过图片题与大题（保证节奏）。
- 不写学习数据，结算不入库。
- 敌方强度只做轻度自适应，尚未做关卡与成长线。
