## 2026-11-23 · v0.7 题库启用开关与战斗范围细化

这一轮解决两个「范围太粗」的问题：古诗文不能只挑重点复习，战斗也不能只按科目选。

### 1. 古诗文启用开关

在 `/texts` 每张卡片右上角有「已启用 / 已停用」开关，详情页也能直接切换。

- 停用的篇目仍然可以读原文、看赏析、点「练本篇」，只是**不进默写专项的抽题库**。
- 列表页顶部显示「启用 N / 77」，提供「只看启用」「全启用」「全停用」。
- 默写专项按启用集合实时重算题量；新增「练启用篇目」按钮，直接练所有已启用篇目的抽句题。
- 存储：`settings.disabledTexts`（存未启用 id，缺省代表全部启用），随进度一起导出导入。

### 2. 战斗出题范围细化

`/battle` 的「出题范围」从单选科目改成多选 + 三级细化：

- **科目级**：点科目卡整科全选/取消，部分选中时显示 `3/58 知识点`。
- **板块级**：展开科目后按知识板块（`group`）分组，点板块名头整块全选/取消。
- **知识点级**：点小节点单选切换。
- 三态推导：子项点满父级自动变全选，全选后取消任一子项立刻降级为「部分选中」。
- 空集合 = 全部题库；选好后顶部实时显示「N 个知识点 · M 题」，本局预估会给出可出题量。
- 牌层：新增 `buildScopedDeck({questions, kpIds, kpStats})`，按知识点集合收题，薄弱度加权不变。

### 3. 自定义难度

难度多出「自定义」一档，两个滑块：

- 每题限时 10~180 秒（步长 5）
- 敌舰结构 40~500（步长 5）

`customDifficulty()` 按血量比例把敌方攻击力按 0.8 次方缩放、护盾按 0.6、回盾按 0.5，避免高血量局变成「一炮被打死」或「每回合回满」。

### 4. 验证

- `npm run check`、`npm run build` 通过。
- DOM 级实测：展开数学 58 个知识点 → 点板块全选 7 个 → 取消 1 个后板块变「部分」；自定义滑块拖到 20s / 260 结构后本局预估同步；带 2 个知识点开战后 HUD 显示「数学 · 2 个知识点 · 标准」。
- 古诗文：停用《涉江采芙蓉》后「启用 76 / 77」，默写题量 226 → 224，卡片变暗；详情页开关切回会提示「已加入默写题库」。

## 2026-11-23 · v0.6 全科题库与古诗文栏目

这一轮的目标：把「题库」从演示规模扩到能真实备考的规模，并给语文补上高考必背古诗文的完整栏目。

### 1. 古诗文栏目（`/texts`、`/text/<id>`）

77 篇高考必背古诗文（诗 23 / 词 15 / 曲 3 / 文 32 / 赋 2 / 辞 2），每篇都有：原文分段、逐条注释、逐段译文、赏析、名句、易错字、高考提示。

- **背诵遮罩**：原文一键变灰，逐行点击揭示，用来检查背诵而不是「看一眼觉得会了」。
- **名句高亮**：详情页把 `famousLines` 在正文里高亮，扫一眼就能看出这篇的主干句。
- **本篇练题**：每篇 5 题，直接开单题或整篇练习；练习记录与其他题目共用 SRS。

数据在 `content/texts/*.json`，格式见 `docs/content-format.md` 的「古诗文栏目」一节。

### 2. 抽句默写题（380 道）

每篇诗文的题都从原文抽句，按考法分五类：

| 类型 | `recite` | 说明 |
| --- | --- | --- |
| 直接默写 | `direct` | 「____」填上下句 |
| 情境默写 | `context` | 给情境让写对应句子 |
| 字词辨析 | `word` | 通假、活用、古今异义 |
| 文化常识 | `culture` | 科举、礼制、称谓 |
| 赏析 | `appreciation` | 手法与情感判断 |

校验器会逐字核对：默写题的第一条答案必须能在正文里找到（异文只能放在后面几条），这样「题目和原文对不上」会被当场抓住。

### 3. 六科知识点覆盖题库

335 个知识点每个都补到 4 题（另每个板块 2 道大题），题目写进 `content/questions/gen-<科目>-<序号>.json`，`source` 标「自编练习」，与高考真题区分开。

题库总量 **1839 道**（单选 734 / 填空 526 / 多选 271 / 判断 211 / 大题 97），加上原有 25 道示例题与 18 道真题，知识点覆盖率 **335 / 335 = 100%**，平均 4.8 题/知识点：

| 科目 | 知识点 | 覆盖 | 平均题量 |
| --- | --- | --- | --- |
| 数学 | 58 | 100% | 4.8 |
| 物理 | 56 | 100% | 4.8 |
| 化学 | 56 | 100% | 4.9 |
| 政治 | 67 | 100% | 4.9 |
| 英语 | 48 | 100% | 4.7 |
| 语文 | 50 | 100% | 16.3 |

语文平均题量高是因为古诗文的 380 道抽句题落在这 50 个知识点上。

### 4. 校验工具链

- `npm run check`：TypeScript
- `npm run check:content`：科目/知识点/题目/真题卷/古诗文/质量体检，一次性跑完

- `node scripts/check-qbank-quality.mjs`：选项重复、答案不在选项里、「以上都对」凑数、采分点合计对不上、题干重复

### 5. 界面改动

- 古诗文栏目页：搜索（篇名/作者/名句）、体裁筛选、按体裁分组、每篇显示题量与已练数；顶部「默写专项」随机 20 道抽句题。

### 6. 已知限制

- 自编题库由模型按教材知识点生成，**答案与解析需要你自己抽查**；考频/重难只是估算。
- 古诗文的版本异文（冯虚/凭虚、悟言/晤言）以正文为准，另一写法放在可接受答案里。
- 《苏武传》为节选，删去了李陵劝降与赏赐段落，`excerpt` 与 `examNote` 已注明。
- 题目体量上来后首包变大（题库是静态打包的）：JS 1.63 MB / gzip 892 kB，katex（77 kB）、react（45 kB）、marked（11 kB）已拆成独立 chunk 以利缓存。局域网访问几乎瞬时，公网首次加载偏慢，之后由 Service Worker 接管；后续可以按科目懒加载题库。

## 2026-11-22 · v0.5 真题接入与游戏原型

### 1. 真题作答接入学习系统

以前做完真题只出成绩，数据不回流。现在一次交卷会写三处：

- `attempts`：每题一条记录，`mode: 'paper'`
- `cards`：进入 SRS 排程，按记忆曲线复习
- `wrong`：答错进错题本，连对两次才移出

实现：`src/papers/adapt.ts` 把图片版真题转成学习系统认识的 `Question`（题干用 Markdown 图片，选择题选项只保留 A/B/C/D）；`src/papers/sync.ts` 负责写库。综合题按整题自评得分写入。

验证：答 3 题交卷后 `attempts` 0→3、`wrong` 0→2、`cards` 0→3；知识点页「高分子与聚合反应」显示 1 题、作答 1 次、掌握度 60%。

### 2. 18 道真题标注知识点

用 Windows 自带离线 OCR（`Windows.Media.Ocr`，中文简体）识别 18 张题干图，得到文本后人工对照 56 个化学知识点做映射，每题 1~4 个知识点，并给出难度 1~5。

- 脚本：`scripts/ocr.ps1`（OCR）、`scripts/tag_paper_kps.py`（映射与写入）
- 只补 `kpIds` 与 `difficulty`，**不改题干、答案、解析**
- 结果：18/18 题都有知识点，例如 q10 晶胞 → `chem-crystal`，q13 双电解池 → `chem-electrolysis` + `chem-electrode-equation`

### 3. 综合题自评

成绩页新增「综合题自评」：15~18 题各一条，滑动给分后「记入」，写入一条 `paper` 模式的 attempt（带 `score`/`maxScore`），60% 及格线自动判对错。

同时让「没有采分点的题」在学习流程里也能自评：`AnswerInput` 在大题 `rubric` 为空时显示整题滑块。

### 4. 试卷录入向导

科目页新增「录入真题」（`/paper-import`），三步：卷子信息 → 逐题录入 → 校验导出。

- 图片可上传（存 IndexedDB 草稿）或手填相对路径
- 校验会拦住：id 非法/重复、题号不连续、分值异常、单选答案非 A~D、知识点不存在、题干图缺失
- 导出 `paper.json` 与 `qNN.json` 文本，复制或下载后放进仓库，重新构建生效

验证：用向导导出结构造了一套临时卷，`npm run check:content` 通过后删除。

### 5. 答题驱动战斗原型

科目页新增「星域战斗」（`/battle`），方案见 `docs/battle-design.md`。

- 三档难度（轻松/标准/硬核），敌方结构、护盾、每题限时、反击伤害各不同
- 每回合抽 3 张指令卡，每张卡绑定一道题；答对造成伤害并叠连对倍率，答错指令偏斜并吃反击
- 只读学习数据：抽题权重按掌握度倾斜，薄弱知识点出题更多
- 不写入学习数据，避免同一道题被计两次

### 6. 文档

- `docs/battle-design.md`：三种答题驱动玩法方案与取舍
- `docs/paper-import.md`：录入一套新卷子的完整流程
- `docs/progress.md`：本文件
